# Ark — AI ネイティブなターミナル / SSH クライアント

Ark はリモートサーバー向けの SSH クライアントとターミナルです。AI エージェントは、
あなたがすでに接続しているマシンの上で動作します。ターミナル、SFTP ファイル転送、
サーバー状態は 1 本の実接続を共有するため、エージェントは環境の説明を求めることなく、
リアルタイムの事実から作業を始めます。

**macOS 11+（Apple Silicon および Intel）· Windows x64 · 無料プランあり**

## Ark とは

多くの AI ターミナルツールはチャット欄を開き、あなたが背景を説明するのを待ちます。
Ark はすでに持っているコンテキストを自分で読み取ります。接続先ホスト、使用中の ID、
カレントディレクトリ、稼働中のサービス、リッスンしているポート、そして直前に表示された
出力です。

1 つのコマンドでは終わらない作業では、目的を伝えるだけで構いません。エージェントは
サーバー上で根拠を集め、次の一手を提案し、変更を加える前にあなたの承認を待ち、
実行後に結果を検証します。

Ark はそれ単体で完結した SSH クライアントです。エージェントを一度も有効にしなくても、
毎日の作業に使えるターミナルとして成立します。

## 機能

- **ターミナル** — 1 本の実 SSH 接続上でのシェルセッション、画面分割、履歴、補完。
- **SFTP ファイル転送** — 別のアプリに切り替えることなく、ターミナルの隣で参照・
  アップロード・ダウンロードができます。転送キューは一時停止、再開、再試行が可能です。
- **サーバー状態の可視化** — ID、リソース、サービス、リッスンポート、ウォッチ項目を、
  何をするか決める前に確認できます。
- **SSH 設定のインポート** — 既存のホスト設定を読み込むため、アドレス・ユーザー・認証
  情報を入力し直す必要はありません。
- **接続ホスト数は無制限** — ホスト数はプランによって制限されません。
- **AI エージェント** — サーバーの現在状態を読み取り、複数のステップにわたって根拠を
  追跡し、検証済みの事実とまだ不確かな点を区別して提示します。
- **自分のモデルキーを使用** — カスタムモデルを設定でき、プロバイダーと API キーは
  あなたの管理下に置かれます。
- **インターフェース言語** — English、简体中文、日本語。

## 制御と認証情報

実際のサーバーをエージェントに触らせる前提は、境界が明示されていることです。以下は
有効化を覚えておく必要のあるオプションではなく、製品としての動作です。

- あなたの明示的な承認なしに実質的な変更は行われません。また 1 回の承認は、目の前の
  その操作だけを許可します。
- 変更の前に Ark は、対象サーバー、使用する ID、対象、完全なコマンド、想定される影響、
  そして結果をどう検証するかを提示します。
- SSH 秘密鍵、パスワード、カスタムモデルの API キーはあなたのデバイスに保持されます。
  エージェントがそれらを読み取ることはありません。
- 実行はいつでも中断でき、続きを CLI で仕上げられます。
- 実行の成否、技術的な検証、業務上の健全性は分けて報告されます。「コマンドが通った」が
  「問題が解決した」として提示されることはありません。

## よくある質問

**Ark は SSH クライアントですか、AI アシスタントですか。**
どちらでもあります。単体で使える完結した SSH クライアント兼ターミナルであり、加えて
すでに接続済みのサーバー上で動作するエージェントを備えています。

**AI 機能を使わずに利用できますか。**
できます。Free プランで SSH / CLI セッション、SFTP ファイル転送、接続ホスト数無制限、
ローカル履歴をカバーしています。

**SSH 鍵はどこに保存されますか。**
あなたのデバイス上です。秘密鍵、パスワード、カスタムモデルの API キーはアップロード
されません。

**Ark はどのモデルを使いますか。**
ご自身の API キーを使用するため、プロバイダーと鍵はあなたのものです。

**Linux に対応していますか。**
現時点では未対応です。公開しているのは macOS と Windows x64 です。
